A sun-soaked open-world crime game built from scratch using Three.js for make.fun bounty gta6-01.

## Concept
Play as Ray Delgado in the coastal port city of Sunset Bay. Complete story missions, steal cars, evade the police, and upgrade your ride.

## Controls
- **WASD / Arrow Keys**: Move on foot or drive vehicles
- **E**: Enter / Exit vehicles
- **F**: Punch / Shoot
- **ESC / P**: Pause menu

## How to Play Locally
```bash
node serve.ts
```
Open `http://localhost:8080` in your browser.
